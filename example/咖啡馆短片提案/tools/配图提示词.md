# 配图登记表（一杯的时间）

> 每张图一行。「来源」只有三种：`出图`（AI 生成）、`用户给`（实拍、官方图、截图）、`参考`（别人的作品，图位上写出处）。
> **一步接一步**：后一步的图拿前一步的图当底。交给出图工具的原话在 `出图记录/交给出图工具的话.md`。
> 这份示例的图上没有挂「效果预览」的角标（默认不挂）；哪些是生成的，都记在这张表里。

| 文件名 | 用在哪页 | 来源 | 底图 | 说明 |
|---|---|---|---|---|
| `pencil-01…04.jpg` | 铅笔分镜 | 出图 | 无 | 一张 2×2 的总图（`出图记录/铅笔_01到04.jpg`），用 `tools/cut_sheet.py` 切成四格 |
| `board-01…04.jpg` | 分镜图、预演 | 出图 | 铅笔那张总图 | 把铅笔稿交回去上色，一格对一格（`出图记录/成图_01到04.jpg`），`--mode photo` 切开 |
| `cover.jpg` | 开场、封面、效果预览 | 出图 | 无 | 主视觉：窗边的一杯咖啡 |
| `moments.jpg` | 效果预览 | 出图 | `cover.jpg` | 朋友圈的手机截屏，直接生成的一张图，不是拿代码拼的界面 |

声音：`assets/audio/music-1.mp3`、`music-2.mp3` 是合成的两条节拍（60 拍和 120 拍），只是给示例用的，换成你自己的音乐。
