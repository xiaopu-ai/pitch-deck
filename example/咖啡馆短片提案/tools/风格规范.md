# 风格规范（一杯的时间）

> 定风格以后填。之后每一轮批注里的共性问题，追加到最后一节。改了这里，记得同步 `assets/deck.css` 里的 `:root` 变量。

## 方向
- 参考：（网站 / 片子 / 品牌，附链接）
- 一句话：（例：深色底 + 一个橙色强调，标题用宋体大字，动效克制）

- 其余文字：

## 字号（硬规矩）
- 辅助小字 ≥ 22px；标签、说明 24–32px；正文和条目 30–36px；眉标 28px；标题 46–140px；大数字 120–132px。

## 版式（硬规矩）
- 画布 1920×1080，左右各留 160px；顶部 0–130px 是 logo 和右上角小字，内容从 150px 往下。
- 主要内容放在 810px 线（3/4 高度）以上，900px 以下只放极小的辅助字。
- 句末标点悬挂：`<span class="hang">，</span>`。

## 动效
- 出现：透明度 + 14px 位移 + 由虚到实，0.8 秒，错时 0.12–0.15 秒。
- 不用：（例：回弹、荧光笔、跳动计数器）

## 图
- 出图的风格后缀：见 `tools/配图提示词.md`。
- 出图生成的图一律带「效果预览」角标；参考图写出处。
