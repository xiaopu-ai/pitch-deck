# 引擎与写法（第一次写页面前读）

## 一页的骨架
```html
<!-- ====== P07 ====== -->
<section class="slide c07" data-id="P07" data-title="屏标题（和稿子里一字不差）">
  <div class="hd"><span class="eb" data-s="0" style="--d:.2s">眉标</span><h3 data-s="0" style="--d:.3s">一行标题</h3></div>
  <div class="ba">……第 0 下、第 1 下出来的东西……</div>
</section>
```
- 画布固定 1920×1080（`#stage`），引擎按窗口大小等比缩放。所有位置按这个尺寸写 px。
- section 上除了页前缀 `cNN`，还可以写一个整页的页型（`p-open`、`p-music`……见 `页型与版式.md`）。页型和页码无关。
- 页前缀 `cNN` 跟编号走：P07 → `.c07`。同一屏拆成两页时用 `P07b` / `.c07b`（这种页没有对应的讲稿）。
- 页的顺序 = `index.html` 里 section 的顺序。
- 这一页自己的样式写进 `assets/pages.css`，每条规则以 `.c07` 开头。

## 分步：第几下出现什么
| 写法 | 意思 |
|---|---|
| `data-s="n"` | 第 n 下出现（0 = 一进页就出现）。引擎按这页最大的 data-s 算有几下，走完自动翻页 |
| `style="--d:.3s"` | 出现时的延迟，用来错时（一组元素 .12–.15s 一个） |
| `.cNN.st1 .x{…}` | 整页状态：第 ≥1 下时 section 上有 `st1`，第 ≥2 下有 `st2`……用来推镜头、压暗、换布局 |
| `.st1:not(.st2)` | 「只在第 1 下」 |
| `<b class="mk" data-s="2" data-cue="说明"></b>` | 隐藏标记：某一下只有整页状态变化、没有新元素出现时必须放，不然引擎数不到这一下，会直接翻页 |
| `data-cue="说明"`（写在任何 `data-s` 元素上） | 演讲者那一屏「下一下」旁边显示的提示。不写就取那一步出现的字 |
| `class="x1"`…`x4` | 到第 n 下自己退场（淡出 + 上移 + 模糊） |
| `data-hero="0,2"`（写在 section 上） | 第 0、2 下算整屏大图：logo 自动换到底部正中 |
| `class="slide cNN light"` | 亮色页（底、字、顶栏小字自动变） |

提案和汇报一页用 1–3 下就够了。下数越多，现场越容易按乱。

## 踩过的坑
1. **不许自己加状态类**（比如在脚本里给 section 加一个 class）。引擎只会清自己的 `stN`，你加的类留着，回到这页时会先把上次的状态倒放一遍。整页状态一律用 `.stN`。
2. **只有状态变化的那一下要放 `.mk`**，否则那一下被跳过。步骤要连着：有第 2 下就得有第 1 下。
3. **`transition:` 简写会冲掉出场延迟**。`[data-s].on` 靠 `transition-delay:var(--d)` 错时；后写的规则里一旦用了 `transition:` 简写，延迟就没了。只写 `transition-property` / `transition-duration`，或者补一条 `.cNN .x.on{transition-delay:var(--d)}`。
4. **优先级**：`[data-s].on` 是两个选择器，你写的 `.cNN .x` 也是两个，后写的赢。想在某一下把出现过的元素藏起来，用三个以上（`.slide.st2 .x`）或者用 `x2`。
5. **元素自己有 transform 的**（比如居中用的 `translateX(-50%)`），出场位移会把它冲掉。外面套一层 div，把 `data-s` 放外层。
6. **`background:` 简写会冲掉图**。给图位加样式时只写 `background-color` / `background-image`，别用简写。
7. **图片路径**：html 里写 `assets/img/x.jpg`，css（在 assets/ 下）里写 `url(img/x.jpg)`。
8. **字体**：只用放映电脑上有的字体，或者把字体文件放进 `assets/fonts/` 用 `@font-face` 引。

## 鼠标和能点的东西
- 鼠标是看得见的。鼠标一动，左下角出来一条工具条：上一步、下一步、**演讲者视图**、全部页面、全屏；不动三秒自己收起。
- 点任何一个图位（`.im`）放大，再点一下收起。
- 带 `data-ui` 的元素（和它里面的东西）是控件，点它不翻页。自己加按钮、加能点的东西，记得写上 `data-ui`。
- 换页时声音自动停、放大的图自动收起。
- 这些都只在观众屏上有；演讲者那一屏和它里面的小预览不加。

## 页面脚本 `assets/pages.js`
- `window.onStep = (页, 第几下, section) => {…}`：每一下都会调。模板里已经处理了亮色页、大图页顶栏、标签滑块、桂冠，后半截是工具条、点图放大、试听、预演。要加别的，写在最后面，**别加状态类**。
- `window.DECK.go(页, 第几下)` 可以跳页（页从 0 数）；`DECK.i`、`DECK.step` 是现在在哪。
- 某页要动画：只在这页 `.active` 时跑，离开时停。

## 讲稿和批注的格式（引擎读的）
- `assets/notes.js`：`window.NOTES = [{id:'P01', title:'屏标题', paras:[[第几下, '文字'], …]}]`，由 `tools/make_notes.py` 从 `tools/稿子.md` 生成。
- 演讲者那一屏每一下只显示这一下的段落。`▸` 开头的显示成要点（手卡）；`**粗体**` 加重；全角（……）显示成黄色的提示；`⚠️` 开头是待核。
- 「建议用时」按字数估（每分钟 220 字），要点的字也算在内，会略偏长，当参考看。
- 批注存在浏览器里（按项目分开），导出的 .md 每条带 `?s=页&t=第几下` 和〔框：x y 宽×高〕。

## 网址参数
- `index.html?s=5&t=2`：直接跳到第 6 页（从 0 数）的第 2 下。
- `?presenter=1`：演讲者那一屏（平时按 S 打开）。
- `?preview=1`：演讲者那一屏里的小预览用的，只显示不响应按键。

## 按键
| 在哪 | 键 | 做什么 |
|---|---|---|
| 观众屏 | → / 空格 / 回车 / 点空白处 | 下一步（这页走完自动翻页）。点图是放大，点控件是控件自己的事 |
| | ← / 退格 | 上一步 |
| | S（或工具条上的「演讲者视图」） | 打开演讲者那一屏 |
| | F | 全屏 |
| | O | 看全部页面，点哪页跳哪页 |
| | B 或 . | 黑屏 / 恢复 |
| | A | 记一条批注（可以在画面上拖框） |
| | L | 批注清单：复制、下载 .md |
| | Home | 回第一页 |
| 演讲者那一屏 | → ← 空格 | 翻页，观众屏跟着走 |
| | E | 现场改备注（只存在这台电脑的浏览器里） |
| | + / − | 备注字号 |
| | P | 开始 / 暂停计时 |
| | R | 计时归零 |
| | Esc | 关闭 |

两边怎么同步：同一个浏览器里的两个窗口直接互相发消息，不经过网络。所以演讲者那一屏要从观众屏按 S 打开，两个窗口要在同一台电脑、同一个浏览器里。
