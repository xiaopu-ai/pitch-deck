# 页型与版式

样式都在项目的 `assets/deck.css` 里。先用现成的页型，不够再在 `assets/pages.css` 里补，不要每页发明新版式。

## 硬规矩
- **画布 1920×1080**，左右各留 120px。顶部 0–130px 是顶栏（左边标题、右上角小字），内容从 138px 往下，可以用到 1000px 左右。在会议室里讲、后排会被前排挡住的，把要紧的内容放在 810px 线以上。
- **字号下限**：辅助小字 ≥ 22px；标签、说明 24–32px；正文和条目 30–36px；眉标 26px；标题 46–200px；大数字 100–200px。
- **颜色只有三个**：黑底、白字，黄只做强调（眉标、编号、选中的那一个、最要紧的一条线）。亮色页是纸白底黑字，铅笔稿、调研墙放在亮色页上。
- **字远少于要说的话**：一页一个标题，加一组图，或一组数字，或三条以内的要点。要说的话写进讲稿，不上画面。
- **字不能压在图、线、别的字上**。

## 图位（所有页型共用）
```html
<div class="im" style="background-image:url(assets/img/x.jpg)"></div>            <!-- 用户给的图 -->
<div class="im gen" style="background-image:url(assets/img/y.jpg)"></div>        <!-- 出图生成的：写 gen。角标默认不显示 -->
<div class="im" data-tag="出处" style="…"></div>                                 <!-- 别人的作品：这一行字一直显示 -->
<div class="im todo" data-todo="待出图：窗边的杯子"></div>                        <!-- 还没出：斜纹占位 -->
```
- 图位的大小由它所在的页型决定，图自动铺满、居中裁切。
- **任何一个图位，放映时点一下就放大**，再点一下收起。
- 想在同一个图位里「先铅笔稿、按一下换成成图」：里面叠一层 `<div class="lay" data-s="1" style="background-image:url(…)"></div>`。
- 要显示「效果预览」角标：在 `index.html` 的 `<div id="stage">` 上加 `class="tags"`，所有 `gen` 的图位右下角就带上；整屏图（`.pic`）在那一页单放 `<i class="tg">效果预览</i>`。

## 整页的页型（视觉提案用）
写在 section 上：`<section class="slide c07 p-music" …>`。**和页码无关**，删页、换顺序都不用改样式。里面的结构照 `skeletons/visual/pages.html` 抄，那里每一屏上面都有一行注释。

| class | 是什么 | 里面有什么 |
|---|---|---|
| `p-open` | 开场：整屏图 + 左下角大标题 | `.cam>.pic`、`.vl`、`.t`（眉标、`h1`、一句话，中间的 `<i>` 是一条黄线）。section 写 `data-hero="0"` |
| `p-brief` | 命题 | `.col`（眉标 + `h2`）、`.nums`（三行，每行一个大数字）、`.idx`（一排目录，`style="--n:几项"`） |
| `p-research` | 调研 | `.wall`（4×4 的格子，`w2 h2` 是大的那张，图位写 `data-tag="出处"`）、`.find`（三条结论） |
| `p-tone` | 色调 | `.gr`（2×2：左边原样 `a0 b0`，右边调完 `a1 b1`，中间两个箭头）、`.pal`（一列色板，颜色写在 `--c` 上） |
| `p-grade` | 方案 | `.ui`（一张大图 + 一行图注）、`.steps`（五步，每步一个编号） |
| `p-story` | 故事线 | `.sk`（一页草稿）、`.bar`（三段的长短）、`.acts`（三段各讲什么） |
| `p-frames` | 风格帧 | `.big`、`.s1`、`.s2` 三个 figure，图注里 `<b>` 是黄色的小牌 |
| `p-music` | 音乐 | `.cands`（几张卡片 `.cd`，选中的加 `pick`，`style="--n:几条"`）、`.why`（一句结论）。卡片里的按钮见下面「能点的东西」 |
| `p-cut` | 转场 | `.pair`（两个 figure，中间一个 `.cut`；两格正中各有一条黄线，用来对位置）、`.rules`（三条） |
| `p-play` | 预演 | `.ply`，见下面「能点的东西」 |
| `p-hero` | 主体 | `.src`（手里的原图）、`.ar`、`.o1 .o2 .o3`（三个场景，`o1` 最大）、`.bl`（左下第三样，可删）、`.nt`（一行说明） |
| `p-cover` | 封面 | `.row` 里三个 `.k`：`w`（16:9）、`p34`、`p916`，图位里的 `.ti` 是压在图上的片名 |
| `p-preview` | 效果预览 | `.ph`（手机，里面放竖图）、`.sc`（横图） |
| `p-next` | 下一步 | `.t`（眉标、`h1`、一句话）、`.dc`（要对方定的几件事，`style="--n:几件"`） |

**一屏的分镜格子 `.g12`**（不是整页页型，直接放在 section 里）：默认 4 列，8 格两排、12 格三排；4 格写 `style="--n:2;left:330px;right:330px"`。铅笔稿和成图用同一套格子，一一对应。成图的每格里放 `<b>01</b>`，左上角出一个黄色的编号。

## 能点的东西
约定：带 `data-ui` 的元素是控件，点它不翻页；别的地方点一下还是「下一步」。脚本在 `assets/pages.js`，不用改。

**试听**：音频放 `assets/audio/`。
```html
<div class="cd pick"><b>60<small>拍 / 分钟</small></b><h4>慢的</h4><p>一句话</p>
  <button class="pl" data-ui data-audio="assets/audio/music-1.mp3" aria-label="试听"></button><div class="pg"><i></i></div></div>
```
**预演**：分镜图按每个镜头的长短切，配上音乐（没写 `data-audio` 也能放，只是没声音）。
```html
<div class="ply" data-s="0" data-ui data-audio="assets/audio/music-1.mp3">
  <div class="scr"><div class="fr"></div><span class="no" data-f="no">01</span><i class="pp"></i></div>
  <div class="side">…<div class="v" data-f="name"></div>…<span data-f="t">0.0</span> / <span data-f="total">0</span> 秒…</div>
  <div class="strip"></div>
  <ol class="shots">
    <li data-len="4" data-img="assets/img/board-01.jpg" data-cam="远景">清晨，门口亮起一盏灯</li>
    <li data-len="8" data-img="assets/img/board-02.jpg" data-cam="特写" data-mark>水柱落下</li>
  </ol>
</div>
```
- `data-len` 这个镜头几秒；`data-img` 哪张图；`data-cam` 景别；`data-mark` 是要强调的镜头（下面那一格是黄的）。
- 各个镜头的秒数加起来要等于总长；剪辑点最好落在音乐的小节线上（一小节几秒 = 240 ÷ 每分钟拍数）。
- 别处想「从第 k 个镜头放起」：给那个元素加 `data-ui data-play-from="k"`（转场那一屏的「切」就是这样）。

**工具条、点图放大**是自动有的，不用写。

## 小一号的页型（两种骨架都能用）

### 页眉 `.hd`
图多的页用它，只占一行，给下面的图让地方。
```html
<div class="hd"><span class="eb" data-s="0">分镜</span><h3 data-s="0">30 秒，8 个镜头</h3><p data-s="0">右边一句补充</p></div>
```

### 参考板 `.board`
前期调研用：想要的感觉，拿几张参考说清楚。6 列 × 2 行，格子用 `w2` / `w3`（占几列）、`h2`（占两行）拼，一般 5 张：一张大的占两行，四张小的。说明压在图的左下角，每张只写「看它的什么」。下面可以放一排色卡。
```html
<div class="board">
  <figure class="w2 h2" data-s="0"><div class="im" data-tag="参考 · 出处" style="…"></div><figcaption>逆光里的蒸汽</figcaption></figure>
  <figure class="w2" data-s="0" style="--d:.12s"><div class="im" …></div><figcaption>手的特写</figcaption></figure>
  …
</div>
<div class="sws" data-s="1"><i style="--c:#b5622d"></i><i style="--c:#f1e6d6"></i><span>焦糖棕打底，奶白提亮</span></div>
```

### 分镜格子 `.sb`
每格：左上角编号 + 16:9 的图 + 一行镜头说明。`<em>` 里写「景别 · 运镜 · 几秒」，后面一句写拍什么（15 个字以内，一行放得下）。
```html
<div class="sb" style="--n:4">
  <figure data-s="0"><div class="im gen" style="…"><b>01</b></div><figcaption><em>特写 · 慢推 · 4 秒</em>水柱落下，粉层鼓起来</figcaption></figure>
  …
</div>
```
- `--n` 是列数。8 格用 `--n:4`（两排）；3–4 格一排，图更大，这时把位置往下放一点：`style="--n:3;top:270px"`。
- 6 格：`style="--n:3;left:360px;right:360px"`（收窄一点，两排才放得下）。
- 草图那一版在 `.sb` 上加 `sk`（纸底 + 虚线框）。草图和成图各一页，格子一一对应，对方才看得出是同一套。
- 时长加起来要等于总长，讲稿里说一句。

### 前后对比 `.ba`
左边「之前 / 原图」，右边「之后 / 出图」，中间一个箭头。右边那组一般放在第 1 下。
```html
<div class="ba">
  <figure class="b" data-s="0"><div class="im" style="…"></div><figcaption><em>之前</em>一句话</figcaption></figure>
  <div class="arr" data-s="1"></div>
  <figure class="a" data-s="1"><div class="im gen" style="…"></div><figcaption><em>之后</em>一句话</figcaption></figure>
</div>
```
**一张图出几个场景**（主体那一页）：`.ba` 上加 `fan`，右边换成一组小图。
```html
<div class="ba fan">
  <figure class="b" data-s="0"><div class="im" style="…"></div><figcaption><em>原图</em>从哪来的</figcaption></figure>
  <div class="arr" data-s="1"></div>
  <div class="as" style="--n:2">
    <figure data-s="1"><div class="im gen" style="…"></div><figcaption>清晨的窗边</figcaption></figure>
    …（2–4 张）
  </div>
</div>
```

### 落地预览 `.mock`
做出来以后放在哪看：手机里（`.phone`，竖版）、大屏上（`.screen`，横版）。可以只放一个，也可以放两个手机。
```html
<div class="mock">
  <figure class="dev phone" data-s="0"><div class="fr"><div class="im gen" style="…"></div></div><figcaption>手机里：竖版，发在哪</figcaption></figure>
  <figure class="dev screen" data-s="1"><div class="fr"><div class="im gen" style="…"></div></div><figcaption>大屏上：横版，哪里的屏</figcaption></figure>
</div>
```
手机里那张要用竖版的图（9:16 左右），横图会被裁掉两边。

### 条目表 `.kv`
左边 `.col` 放标题，右边一行一条。下一步、镜头语言、要对方定的事都用它。最多 5 行。只有两三行时整组偏上，在 `assets/pages.css` 里把两边一起往下挪：`.c06 .col{top:240px}` `.c06 .kv{top:256px}`。
```html
<div class="col"><div class="eb" data-s="0">下一步</div><h2 data-s="0">今天请您<br>定两件事</h2><div class="rl" data-s="0"></div></div>
<div class="kv">
  <div class="r" data-s="1"><b>第一件</b><span>8 个镜头的顺序<small>定了才能约拍摄时间</small></span></div>
  …
</div>
```

## 通用件
| class | 是什么 | 用法要点 |
|---|---|---|
| `.hx` / `.hx.mid` | 居中大标题（眉标 `.eb` + `h1` + `p`） | 开场、封面、一句结论。在图上加 `.onpic` 给字加阴影 |
| `.cam` + `.pic` + `.vl` | 整屏图 + 慢慢推近 + 压暗 | 封面页。section 写 `data-hero="0"`；`.cam.push` 第 1 下推镜头，`.vl.dim` 第 1 下压暗 |
| `.col` | 左栏（眉标 + `h2` + 细线 `.rl`） | 左 160，宽 580；右边配 `.kv` 或 `.pn` |
| `.acc` + `.a1/.a2/.a3` | 手风琴：第 1 下展开 a1，第 2 下 a2…… | 过程分两三步讲。第 2、3 下要放 `.mk` |
| `.pn` + `.tabs` + `.scs` | 右侧面板，里面按第几下切换 | 配手风琴用 |
| `.stats`（`--n:列数`，`.c` 居中） | 一排大数字 | `<b>3<small>周</small></b><span>说明</span>`；数字要有出处 |
| `.lrs` + `.lr` | 桂冠（奖项、排名） | 有真的奖项、排名才用 |
| `.light` | 亮色页 | 写在 section 上。数字页、对比页用亮色，和深色页错开 |
| `.eb` / `.hang` / `.serif` | 眉标 / 标点悬挂 / 宋体 | `<span class="hang">，</span>` |

## 动效（默认是克制的，一般不用改）
- 出现：透明度 + 位移 14px + 由虚到实，0.8 秒，一组元素错时 0.12–0.15 秒。
- 先图后字：图先进来，字晚 0.3–0.6 秒。
- 整屏图一直慢慢推近（16 秒）。
- 不用：回弹、跳动的计数器、荧光笔、循环闪烁。
- 每一下都要看，不只看最后一下；翻回上一页再翻回来，不能有倒放。
