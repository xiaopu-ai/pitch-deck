# 两种骨架

骨架是起点。材料少就并页、删页，材料多就把某一页拆成两页；但顺序别乱，**最后一页一定是「要对方定什么」**。

## 一、一般汇报（`--kind report`，6 页）
事情做了，讲结果、要支持。对方时间少，所以结论放最前面。

| 页 | 画面上放什么 | 页型 | 讲稿要点 |
|---|---|---|---|
| 开场 | 题目 + 一句话：这件事现在到哪了 | 居中大标题 | 今天讲哪件事、讲多久、最后要定什么 |
| 结论 | 一句结论（不超过两行）+ 三条依据 | 左栏 + 条目表 | 先把结论说出来，再说凭什么。每条依据带出处 |
| 过程 | 两三个阶段，每个阶段留下的东西（截图、草稿、表格） | 手风琴 + 面板 | 过程是给结论作证的：做过什么、试过什么没成。有图就放图 |
| 效果：数字 | 三个数字，每个下面一行说明 | 一排数字（亮色页） | 每个数字说明什么；出处和时间范围。没有数字就删掉这一页，不要凑 |
| 效果：前后对比 | 之前的样子、之后的样子 | 前后对比 | 之前的问题在哪，变了什么 |
| 下一步 | 接下来做什么（谁、哪天前）+ 要对方定的那一件事 | 左栏 + 条目表 | 要定的事放最后一下，说清楚不定会卡住什么 |

## 二、视觉前期提案（`--kind visual`，16 屏）
片子还没拍、活动还没办、东西还没做。对方看不见结果，所以把**过程稿**一张张摆出来：让他看见它会是什么样，也看见每一步是怎么想的。结果重要，过程更重要，过程是用来托举结果的。

| 屏 | 页型（section 上的 class） | 画面上放什么 | 图从哪来 | 讲的时候 |
|---|---|---|---|---|
| 开场 | `p-open` | 整屏主视觉 + 片名 + 一句话 | 出图（最后出，从分镜图里挑最好的方向） | 今天看的是前期提案；东西还没做，先定方向 |
| 命题 | `p-brief` | 一句话的命题 + 三个数（多长、手里有什么、有什么限制）+ 一排目录 | — | 这次要做什么；提案分几块 |
| 前期调研 | `p-research` | 一墙参考截图 + 三条结论 | **真截图**：别人公开的作品、官网，写出处 | 找了哪几家；三条结论各管后面的哪一块 |
| 风格和色调 | `p-tone` | 原样和调完各两张 + 色板 | 原样是用户的素材；调完的拿原样当底出 | 定的是方向；色板从调完的图里取 |
| 调色方案 | `p-grade` | 一张大图 + 五步 | 出图，或真的截屏 | 一步一步怎么做，带数字。不是片子就改成「做法」 |
| 故事线 | `p-story` | 最早的一页草稿 + 三段 | 出图：本子上的一页小方块 | 一句话的故事；分几段、各多长 |
| 铅笔分镜 | `.g12` | 全片的镜头，一格一个 | 出图：铅笔稿，2×2 一张 | 先看顺序和构图；这一步改最省事 |
| 风格帧 | `p-frames` | 一大两小，三张定下全片的样子 | 出图，或拿调完的素材 | 上色之前先定这三张 |
| 分镜图 | `.g12` | 和铅笔分镜同一套格子 | 出图：**把铅笔稿交回去上色** | 一格对一格；是效果图不是实拍 |
| 音乐 | `p-music` | 几条备选（能点开听）+ 选哪条、为什么 | 用户给的音乐放 `assets/audio/` | 让对方听；说清为什么选这一条，节奏怎么排 |
| 转场 | `p-cut` | 最花心思的那一刀：两格并排，中间一个「切」 | 分镜里的两格（先铅笔，按一下换成图） | 一共几个剪辑点；这一处凭什么接得上 |
| 预演 | `p-play` | 分镜图配上音乐放一遍 | 分镜图 + 选定的音乐 | 这就是成片的节奏 |
| 主体 | `p-hero` | 手里的一张图 → 几个场景 | 原图用户给；场景**拿原图当底**出 | 主体不改，只换环境；建议用哪一张 |
| 封面 | `p-cover` | 一张主视觉裁三个尺寸 | 开场那一张 | 横的竖的都从它裁 |
| 效果预览 | `p-preview` | 手机里、大屏上 | 出图：一张手机截屏、一张现场的照片，拿封面当底 | 发在哪、放在哪 |
| 下一步 | `p-next` | 定了以后做什么 + 要对方定的三件事 | — | 一件一件说；定了就开工 |

**不必 16 屏都做。** 材料少、时间短，就删：示例是 9 屏（开场、命题、铅笔分镜、分镜图、音乐、预演、封面、效果预览、下一步）。页型和页码无关，删掉、换顺序都不用改样式；删完把「命题」那屏的目录和各屏眉标上的编号改一下。**最后一屏一定是「要对方定什么」。**

### 图的链条
```
调研截图（真的）
故事线草稿 ──→ 铅笔分镜 ──→ 分镜图（拿铅笔稿当底）──→ 预演（配上音乐）
                              │
用户给的原图 ──→ 主体放进场景    └─→ 主视觉 ──→ 封面三个尺寸 ──→ 手机里、大屏上
```
后一步都拿前一步的图当底，所以全片的人、物、光、色是一套。跳着出（比如直接出封面）就会和分镜对不上。

### 每个决定都要有「为什么」
- 色调：调研里别人是什么颜色，我们为什么走这一路。
- 镜头：手里有什么素材，决定了哪些镜头拍得到。
- 音乐：备选的几条各是什么速度、什么感觉；能量的就量（速度、一小节几秒），量出来才好排镜头的长短。
- 转场：大多数是硬切；只挑一处花心思，说清两格凭什么接得上。

### 不是片子怎么套
同一副骨架换个说法就行：
- 活动：调研（别人的活动现场）→ 色调（主色、物料的颜色）→ 流程（故事线）→ 动线草图（铅笔分镜）→ 现场效果图 → 音乐 → 主视觉 → 物料 → 线上线下的样子 → 要定的事。
- 产品页或小程序：调研（同类的页面截图）→ 线框草图 → 效果图 → 关键页 → 首屏 → 手机里、电脑上 → 要定的事。效果图容易被当成已经做好的界面，放之前跟用户说一声。

## 压缩和拆分
- 5 分钟以内：6 到 9 屏。调研、色调、故事线并进讲稿，不单做页；留下分镜、音乐、预演、效果预览和要定的事。
- 15 分钟以上：16 屏都做；分镜可以拆成两屏（每屏 4–6 格，格子更大）；主体可以每个场景单独一屏。
- 一页讲不到半分钟的，并到前后页去。
