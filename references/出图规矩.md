# 出图规矩

用宿主自带的出图能力（哪家都行）。这里管的是：怎么让它出、顺序、登记、标不标。

## 第一条：图让出图工具直接生成，不要用代码画
线稿、铅笔分镜、手机里的界面、软件界面、物料的效果图，都是**写好提示词，让出图工具出一张图**。不要拿 SVG 画线稿，不要拿网页拼一个手机界面：那样出来的东西一眼假。
如果你是在代替用户调用另一个会出图的工具，交代时写清「只出图，不要写网页，不要用代码画图、拼界面」。

## 一步接一步
1. **先登记，再出图**。每张图在项目的 `tools/配图提示词.md` 里占一行：文件名、用在哪页、来源、底图、说明。
2. **后一步拿前一步的图当底**。出图时把底图一起给进去，写清「保持构图，只把铅笔稿变成拍出来的画面」「这台车照原图，一点不改，只换环境」。
3. **同一套图共用一段画风的话**，原样贴在每条提示词前面（见下面的例子）。
4. **先出两三张给用户看**，风格对了再出剩下的。每张只出一次，不对就改提示词再出，别原样重抽。
5. 出完自己看一眼：字对不对、有没有多出来的字、主体变没变形、和别的图是不是一套。
6. 已经有的图不重出。

顺序（视觉提案）：调研截图 → 故事线草稿 → 铅笔分镜 → 风格帧 → 分镜图（拿铅笔稿当底）→ 主体放进场景（拿原图当底）→ 封面 → 手机里、大屏上（拿封面当底）。

## 提示词怎么写（拿去改）

### 铅笔分镜：一张图里画 2×2 四格
```
A professional film storyboard working sheet, hand-drawn. Medium: soft graphite pencil, charcoal and cool-grey
marker wash on off-white storyboard paper. Strictly greyscale. Loose, fast, confident gestural linework with
visible construction strokes. Strong contrast, from deep charcoal blacks to paper-white highlights. A few bold
hand-drawn arrows show how the subject or the camera moves. It must look like a real storyboard artist's working
sheet. NOT a clean ink engraving, NOT uniform cross-hatching, NOT a coloring-book outline, NOT vector art.
Layout: one LANDSCAPE 16:9 sheet containing EXACTLY FOUR panels in a regular 2 by 2 grid, all the same size,
each a 16:9 frame with a hand-ruled black border, even gutters and an even paper margin. In the top-right corner
of every panel, a small hand-drawn box with the frame number handwritten inside. No other text.
Panel top-left, number "01": （景别、机位、画面里有什么、主体在哪、怎么动）
Panel top-right, number "02": ……
```
- 要说清「不要什么」：干净的线描、均匀的排线、填色本一样的线稿，都不是分镜师的工作稿。
- 每一格写：景别、机位、主体在画面哪里、怎么动。两格之间要接得上的（比如匹配剪辑），写明「和上一格的那条线在同一个位置」。
- 片名的位置：让它画一个带叉的空方框（分镜里「这里放字」的记号），不要让它写字。
- 出完用 `python3 tools/cut_sheet.py 总图.png assets/img/pencil- 1` 切成一格一张。

### 分镜图：把铅笔稿交回去上色
```
Edit the attached storyboard sheet. Keep the layout exactly: four panels in a 2 by 2 grid, the same sizes and
positions, with clean pure-white gutters. Turn each pencil panel into a finished, photorealistic film frame.
Keep each panel's composition, camera angle, and the position and size of every subject exactly as drawn.
Remove all arrows, corner marks, frame-number boxes and pencil texture.
Look for all four frames (one film, one colour grade): （光、色、质感，三四个词）
```
- 再把每一格拍什么说一遍，它才不会认错。
- 切图：`python3 tools/cut_sheet.py 成图.png assets/img/board- 1 --mode photo --inset 3`。

### 主体放进场景：原图一点不改
```
Edit the attached photo. Keep the （主体） EXACTLY as it is: same angle, same proportions, same colours,
same existing lettering. Do not redesign, recolor or add parts. New setting: （环境、光）.
```
- 把主体身上认得出来的东西一条一条列出来（颜色、几个轮子、车身上的字），列得越细越不走样。
- 出完对着原图核：外形、颜色、字。小字常常是糊的，照实告诉用户。

### 手机里的界面：一张手机截屏
```
A realistic, crisp smartphone screenshot of （哪个 App 的哪个页面）, light mode, portrait 9:16, the screen
content only (no phone body, no hand). （从上到下，一块一块写：状态栏、导航栏、头像、名字、正文、图、时间、
点赞和评论）. Typography and spacing follow the real app. Accurate Chinese characters.
```
- 要出现的字，逐字写进提示词，用引号括起来。要用到的图（比如封面）当底图给进去，写「uses the attached image exactly」。
- 人名、评论用一看就是随手起的，不要用真人。

### 海报和物料
- 海报：先说版式（字在哪、多大、什么字体的感觉、几种颜色），再说画面，最后把要出现的字逐字列出来，并写「No other text」。
- 一样物料出一张：易拉宝、广告牌、手机、杂志、背包、横幅……把海报当底图给进去，写「reproduced exactly and unchanged」。
- 要抠出来摆版的：让它用纯平的亮绿色（#00FF00）当背景，没有影子、没有地面，再自己把绿色去掉。

## 文件
- 存到 `assets/img/`，文件名和登记的一样，用英文小写（`board-03.jpg`）。
- 出图得到的 png 常常一张 2 MB 以上：转成 jpg、宽度缩到 1920 以内再用（一张 300 KB 左右）。`tools/check.py` 会提醒太大的图。
- 交给出图工具的原话留一份在 `tools/出图记录/`，以后要改哪张，照着改。

## 标不标（见 SKILL.md「图和事实的规矩」）
| 图的来源 | 页面上 | 登记表「来源」 |
|---|---|---|
| 出图生成 | 图位写 `class="gen"`。角标「效果预览」默认不显示；用户要标，在 `<div id="stage">` 上加 `class="tags"` | 出图 |
| 用户给的实拍、官方图、截图 | 需要时写 `data-tag="素材"`、`data-tag="官方图"` | 用户给 |
| 别人的作品（参考） | `data-tag="出处"`，一直显示 | 参考 |

- 生成的软件界面、数据看板：对方容易当成真的。放之前跟用户说一声，由用户定。
- 图里出现的数字、文字，出完要一个字一个字核。
- 生成的图里出现了认得出来的真人、别家的商标：不用，重出。

## 没有出图能力，或者额度不够
- 图位留 `class="im todo" data-todo="待出图：……"`，斜纹占位，写清这张要什么。
- 告诉用户缺哪几张；用户可以自己在别处出好放进 `assets/img/`，文件名照登记表。
- 不拿不相干的网图顶上，也不要自己用代码画一张顶上。
