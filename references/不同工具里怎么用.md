# 不同工具里怎么用

这个技能不绑定哪一家。只要宿主能读 SKILL.md、能读写文件、能跑 Python 3，就能用。

## 技能装在哪
- 各家放技能的目录不一样（有的在用户目录下的 `.codex/skills/`，有的在 `.claude/skills/`，有的在项目里），以宿主自己的说明为准。
- 技能里的命令都写成相对技能目录的路径。跑的时候用技能实际所在的位置，比如 `python3 <技能目录>/scripts/new_project.py …`。`new_project.py` 自己会从脚本的位置找到模板和引擎，不认固定目录。
- 宿主不支持技能：把仓库拉到任意位置，让它先读 `SKILL.md`，照着做。

## 项目里的 AGENTS.md
- 建出来的项目根目录有一份 `AGENTS.md`，是给 AI 的项目说明。有的宿主开新对话会自动读它；不自动读的，开工第一件事是读 `AGENTS.md` 和 `进度.md`。
- 做完一步就更新 `进度.md`，上下文满了开新对话也能接上。

## 沙盒
- `make_notes.py`、`check.py`、`new_project.py` 只读写项目文件夹，只用 Python 自带的库，在沙盒里能跑。
- `states.py`、`audit.py` 要起浏览器。很多沙盒不让起（报 `SIGABRT`、`EPERM`、`Operation not permitted`）；这两个脚本起不来时会说一句「视觉自查没做」并正常退出。**这不是错误**，接着往下做：
  1. 回复里照实说「版面没截图看过」。
  2. 请用户双击 `index.html` 翻一遍，有问题按 A 记批注。
  3. 用户愿意的话，请他在自己的终端里跑同一行，把 `tools/out/states.png` 给你看。
- 不要为了截图去申请更高的权限，也不要写「已检查」。
- 宿主自带浏览器、能直接打开本地网页的：可以用它看。注意有的内置浏览器把本地文件当成静态快照，不跑脚本；这时在项目文件夹里起一个本地服务再看：`python3 -m http.server 8000`，打开 `http://localhost:8000/`，看完关掉。

## 出图
- 用宿主自带的出图。没有出图能力的：见 `出图规矩.md` 最后一节。
- 能不能「拿一张图当底再出」各家不一样。不能的，在提示词里把前一张图的内容写细，并在登记表里注明「没有用底图」。

## 给用户看
- 双击 `index.html`（macOS 也可以 `open index.html`）。
- 跳到某一页某一下：`index.html?s=5&t=2`。
- 发给别人：把整个文件夹打包；或者放到任何静态网页托管上（文件夹里就是一个完整的静态站）。讲稿在 `assets/notes.js` 里，会一起出去；不想让对方看到讲稿的，发之前把这个文件清空成 `window.NOTES = [];`。
