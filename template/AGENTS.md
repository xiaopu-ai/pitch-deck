# 项目说明（给 AI）：{{TITLE}}

这是一份**网页版的提案 / 汇报**：`index.html` 双击就能放映，按 S 打开演讲者那一屏。
每次开新对话，先读本文件，再读 `进度.md`，从「下一步」接着做。完整流程在 pitch-deck 技能的 `SKILL.md` 里；找不到技能就照本文件做。

## 文件
| 东西 | 位置 |
|---|---|
| 所有页 | `index.html`：每页一个 `<section class="slide cNN" data-id="PNN" data-title="屏标题">` |
| 讲稿（唯一的来源） | `tools/稿子.md`：每屏写成 `**【屏】标题**`，下面是要说的话和 `▸` 要点 |
| 演讲者备注 | `assets/notes.js`，由 `python3 tools/make_notes.py` 生成，**别手改** |
| 每段话第几下讲 / 待核事实 | `tools/分拍.txt`、`tools/待核.txt`（按屏标题写） |
| 样式 | `assets/deck.css`（骨架 + 通用件 + 提案页型 + :root 配色，不随便改）；每页自己的写在 `assets/pages.css`（每条规则以页前缀开头） |
| 页面脚本 | `assets/pages.js` |
| 放映引擎 | `assets/engine/`（**不要改**） |
| 风格规范 | `tools/风格规范.md` |
| 图 | `assets/img/`，每张先在 `tools/配图提示词.md` 登记 |
| 批注 | `批注/*.md`（用户放映时导出的修改意见） |
| 进度 | `进度.md`（每做完一步就更新） |

## 顺序：一步一步来，到了要停的地方就停
1. 问清楚：给谁看、要他定什么、手里有什么材料、讲多久。记进 `进度.md`。
2. 定骨架：每一页放什么，列给用户看，**等用户点头**。
3. 一页一页出内容和图。后一步的图拿前一步的图当底（草图 → 分镜图 → 场景 → 主体 → 封面）。
4. 每一页都写讲稿：要说的话 + `▸` 要点。
5. 自查，然后告诉用户怎么打开观众那一屏和演讲者那一屏。

## 写页面的硬规矩
- 第 n 下出现：元素写 `data-s="n"`，错时写 `style="--d:.3s"`。引擎按页里最大的 data-s 算这页有几下。
- 整页状态只用引擎给的 `.cNN.st1`、`.cNN.st2`（第 ≥n 下时自动加）；「只在第 1 下」写 `.st1:not(.st2)`。**不许自己加状态类**。
- 某一下只有整页状态变化、没有新元素出现：放 `<b class="mk" data-s="n" data-cue="说明"></b>`，不然引擎数不到这一下。
- 到第 n 下自己退场：加 class `x1`…`x4`。
- data-title 要和稿子里的屏标题一字不差；跑 `make_notes.py` 会核对。
- 画布 1920×1080，左右各留 120；内容从 top 138 开始，可以用到 1000 左右；字 ≥ 22px。颜色只有黑、白、黄。
- 图位一律用 `.im`。出图生成的加 `class="gen"`；角标「效果预览」默认不显示，用户要标就在 `<div id="stage">` 上加 `class="tags"`。
- 整页的页型写在 section 上（`p-open`、`p-music`……），和页码无关。能点的控件要写 `data-ui`，不然点它会翻页。
- **图让出图工具直接生成，不要用代码画线稿、拼界面。**

## 图和事实的规矩
- 每张图的来源都登记在 `tools/配图提示词.md`（出图 / 用户给 / 参考）。图上标不标「效果预览」由用户定，默认不标。
- 生成的软件界面、数据看板，对方容易当成真的：放之前跟用户说一声。讲稿里不写「已经做了」这类没发生的事。
- 数字、引用的话、对方的情况：用户给了才写，没给就问，或者记进 `tools/待核.txt`。**不编**。
- 别人的作品当参考：图位上写出处（`data-tag="出处"`），不说成自己的。

## 自查（做完就跑）
```
python3 tools/make_notes.py     # 讲稿 → 备注，核对每页标题
python3 tools/check.py          # 不开浏览器的检查：讲稿、步骤、图、占位、出图的图位标没标 gen、字号
python3 tools/states.py "页:第几下:等几秒,…"   # 可选：截图看版面。沙盒里起不来会自己跳过，不算错
```
截不了图就照实说「版面没截图看过」，请用户打开翻一遍，不要写「已检查」。
