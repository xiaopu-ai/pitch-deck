# 风格规范（{{TITLE}}）

> 定风格以后填。之后每一轮批注里的共性问题，追加到最后一节。改了这里，记得同步 `assets/deck.css` 里的 `:root` 变量。

## 方向
- 参考：（网站 / 片子 / 品牌，附链接）
- 一句话：黑底、白字，黄只做强调；标题用粗黑体，大数字用窄体；铅笔稿和调研墙放在纸白的亮色页上。（要换风格，改这里和 deck.css 的变量）

## 色值（对应 deck.css 的 :root）
| 用途 | 变量 | 值 |
|---|---|---|
| 最深底 | --k0 | #0b0b0d |
| 面板 | --k1 | #141518 |
| 主文字 / 次文字 / 弱文字 | --t1 / --t2 / --t3 | #f4f4f2 / #cdd0d6 / #8e939c |
| 强调（全场只用一个） | --acc | #f5c400 |
| 亮色页底 / 字 | --L0 / --Lt1 | #f4f2ec / #0b0b0d |

## 字
- 标题：`--head`，粗黑体（苹方）。大数字和英文短标：`--disp`，窄体（Anton，没有就用系统里的 DIN Condensed、Impact）。
- 其余文字：`--sans`。

## 字号（硬规矩）
- 辅助小字 ≥ 22px；标签、说明 24–32px；正文和条目 30–36px；眉标 26px；标题 46–200px；大数字 100–200px。

## 版式（硬规矩）
- 画布 1920×1080，左右各留 120px；顶部 0–130px 是顶栏，内容从 138px 往下。
- 内容可以用到 1000px 左右；在会议室里讲、后排会被挡住的，要紧的内容放在 810px 线以上。
- 句末标点悬挂：`<span class="hang">，</span>`。

## 动效
- 出现：透明度 + 14px 位移 + 由虚到实，0.8 秒，错时 0.12–0.15 秒。
- 不用：（例：回弹、荧光笔、跳动计数器）

## 图
- 出图的风格后缀：见 `tools/配图提示词.md`。
- 出图的图位写 `class="gen"`；角标「效果预览」默认不显示，要显示在 `<div id="stage">` 上加 `class="tags"`。参考图写出处。
